Microclimate.jlThe climate near the ground

hourly above- and below-ground microclimates — radiation, wind, soil heat and moisture, snow and canopy — for biophysical ecology, with units.

Get Started
View on Github
API Reference

🌡️ Soil heat balance

Hourly soil temperature at any depth from a 1-D node-based heat budget, with Campbell and de Vries thermal properties that vary with moisture and texture.

💧 Soil moisture

Infiltration, redistribution and root uptake from Campbell's (1985) Soil-Plant-Atmosphere-Continuum model, tested at continental scale against SCAN, CosmOz and satellite soil moisture.

❄️ Snow

A snow node scheme that grows and shrinks with accumulation and melt, buffering soil temperature from the air above it.

🌳 Canopy

A layer-resolved multilayer canopy — two-stream shortwave, longwave exchange, wind attenuation and leaf temperature — for vegetated sites.

☀️ Radiation

Clear-sky solar geometry from SolarRadiation.jl, cloud-adjusted shortwave and a full longwave/sky-emissivity budget.

🧩 Composable models

Every physical process — soil, snow, canopy, evaporation, convergence — is a swappable component, so alternative model choices can be compared by changing one argument.

📏 Units

Every input and output uses Unitful.jl, and calculations build on FluidProperties.jl for air and water properties.

How to install Microclimate.jl? ​

Microclimate.jl can be installed from the Julia REPL:

julia
julia> using Pkg
julia> Pkg.add(url = "https://github.com/BiophysicalEcology/Microclimate.jl")

Model ​

Microclimate.jl is a Julia implementation of the microclimate model of NicheMapR (Kearney and Porter 2017), extended with a new multilayer canopy. See the Introduction for what a microclimate is, how this package relates to NicheMapR and other land-surface models, and how the package is organised.
